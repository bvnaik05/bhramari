start. Keep the Flutter phone in airplane mode for the first harvest.

Keep contract source, provider setup, and architecture for questions. If a
speech provider is unavailable, use the typed response and state that voice is
using its designed fallback. If the sensor is unavailable, use the labelled
deterministic simulator.
